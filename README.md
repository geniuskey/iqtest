# IQMatrix — 온라인 IQ 테스트

레이븐 누진행렬(Raven's Progressive Matrices) 방식의 30문항 IQ 테스트입니다.
**서버 없이 동작하는 정적 사이트**로 GitHub Pages(`iqtest.euiyun.com`)에 배포하고, 구글 애드센스 광고로 수익을 냅니다.

## 동작 방식

- 문제 생성과 채점은 모두 **브라우저 안에서** 이루어집니다. 응시자마다 다른 시드로 다른 문제가 나옵니다.
- 결과는 서버에 저장하지 않고 **링크 주소 안에 담습니다**.
  - 예: `/#/result/1.4w8bcm.a.fzu.0123...`
  - 링크 안의 코드는 `버전.시드.소요시간.응시일.답안` 형식입니다.
  - 링크를 받은 사람의 브라우저가 같은 문제를 다시 만들어 채점하므로, 똑같은 리포트를 볼 수 있습니다.
- 흐름은 다음과 같습니다.
  1. 응시 (30문항, 25분, 새로고침해도 이어서 풀기 가능)
  2. 분석 중 연출
  3. **순위 먼저 공개** ("상위 10% 이내")
  4. "내 IQ 확인하기 (무료)" 버튼
  5. 전체 리포트: IQ, 영역별 분석, 30문항 해설, 인증서 PNG
- 광고 위치는 랜딩, 분석 중, 순위, 리포트 섹션 사이입니다. 문제 풀이 화면에는 광고를 넣지 않습니다. 잘못 누르기 쉬운 배치는 애드센스 정책 위반이기 때문입니다.

한계도 있습니다.
- 채점 로직이 브라우저에 있으므로, 마음먹으면 정답을 보거나 결과 링크를 조작할 수 있습니다. 무료 오락용 테스트라 감수하는 부분입니다.
- 실제 응시자 분포로 IQ 기준을 보정하는 기능은 서버 버전에만 있습니다.

## 로컬 실행

Node.js 20 이상이 필요하고, 외부 의존성은 없습니다.

```bash
npm start      # 정적 사이트 http://localhost:8080
npm test       # 문제 생성기·채점·결과 링크·서버 버전 테스트
```

## 배포 (GitHub Pages)

`main`에 푸시하면 `.github/workflows/pages.yml`이 실행됩니다. 테스트가 통과하면 사이트 파일만 골라서 배포합니다.

**최초 1회 설정**
1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. 같은 화면의 **Custom domain**에 `iqtest.euiyun.com`을 입력하고 **Enforce HTTPS**를 켭니다.
3. 도메인 DNS에 `iqtest` **CNAME** 레코드를 추가하고, 값은 `geniuskey.github.io`로 지정합니다.

## 애드센스 설정

1. 사이트가 열린 상태에서 [애드센스](https://adsense.google.com)에 가입하고 사이트를 등록하면 게시자 ID(`ca-pub-...`)를 받습니다.
2. `config.js`의 `adsense.client`에 게시자 ID를 넣습니다.
3. 저장소 최상위에 `ads.txt` 파일을 만듭니다. 내용은 `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`입니다. `pub-` 뒤에는 본인 ID를 넣습니다.
4. 커밋하고 `main`에 푸시하면 자동으로 배포됩니다.
5. 승인 후 애드센스에서 **디스플레이 광고 단위**를 만들고, 그 ID를 `adsense.slot`에 넣습니다. 슬롯을 비워 두면 자동 광고만 동작합니다.

개인정보처리방침 페이지(`/#/privacy`)가 포함되어 있습니다. 애드센스 심사에서 확인하는 항목입니다. 로컬에서는 광고 위치가 회색 점선 박스로 보입니다.

## 구조

```
index.html, app.js, style.css, config.js   정적 사이트 (GitHub Pages로 배포)
core/rng.js        시드 기반 난수
core/puzzles.js    3x3 행렬 문제 생성기 (20개 유형, 난이도 1~4) + SVG 렌더러
core/scoring.js    난이도 가중 채점, IQ 환산 (평균 100, SD 15), 순위 구간
core/result.js     결과 링크 코드 인코딩/디코딩, 링크로 리포트 재현
server/            서버 버전 (보존용, 아래 참고)
scripts/           로컬 정적 서버
test/              node:test 테스트
```

`core/`는 브라우저(`<script>`)와 Node(`require`) 양쪽에서 쓰는 공용 코드입니다.

### 문제 생성기

- 오답 보기는 정답의 세 가지 속성을 2×2×2로 조합해 만들고, 그중 한 대각선 쌍을 뺍니다.
- 그러면 정답의 각 속성이 보기 중 정확히 절반에만 나타납니다.
- 그래서 "다른 보기들과 가장 많이 닮은 보기 고르기" 요령의 정답률이 무작위 수준(약 16%)에 머뭅니다. 테스트로도 검증합니다.

## 서버 버전 (나중에 유료화할 때)

`server/`에는 유료 리포트를 팔 수 있는 Node 서버 버전이 그대로 보존되어 있습니다.

- 서버가 채점하고 정답을 브라우저로 보내지 않습니다.
- 결제를 확인한 뒤에만 IQ를 공개합니다.
- 토스페이먼츠 실결제를 지원합니다.
- 응시 데이터가 300명 이상 쌓이면 실제 분포로 IQ 기준을 보정합니다.

```bash
npm run server   # http://localhost:3000
```

유료화하려면 다음이 필요합니다.
- 사업자등록과 토스페이먼츠 가맹 심사
- `PAYMENT_PROVIDER=toss` 및 키 설정 (`.env.example` 참고)
- 서버(VPS 등) 배포

> 이 테스트는 재미와 자기 이해를 위한 온라인 추정 검사로, 임상 지능검사를 대체하지 않습니다.
