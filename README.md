# IQMatrix — 온라인 IQ 테스트

레이븐 누진행렬(Raven's Progressive Matrices) 방식의 30문항 IQ 테스트 웹 서비스입니다.

수익 모델은 설정 하나로 바꿀 수 있습니다.

| `PAYMENT_PROVIDER` | 방식 |
| --- | --- |
| `none` (기본값) | **전부 무료 + 구글 애드센스 광고**. 사업자등록 없이 시작할 수 있습니다. |
| `mock` | 유료 리포트 흐름을 테스트 결제로 시연 (실제 청구 없음) |
| `toss` | 유료 리포트 + 토스페이먼츠 실결제 (사업자등록, 가맹 심사 필요) |

## 사용자 흐름 (무료 모드)

1. **랜딩** → 테스트 안내 → 응시 (30문항, 25분 타이머, 건너뛰기 및 이전 문제로 이동 가능, 새로고침해도 이어서 풀기 가능)
2. **분석 중 연출** (약 4초, 광고 노출)
3. **순위 먼저 공개**: "상위 10% 이내"처럼 구간만 보여 주고 IQ 숫자는 잠가 둡니다. 궁금증을 만든 뒤 "내 IQ 확인하기 (무료)" 버튼을 누르게 합니다.
4. **전체 리포트**: 정확한 IQ와 백분위, 분포 그래프 위의 내 위치, 영역별·난이도별 정답률, 30문항 해설, 인증서 PNG 다운로드
5. 결과 링크(`/#/result/:id`)로 들어오면 바로 전체 리포트가 열립니다. 공유받은 사람은 순위 단계를 거치지 않습니다.

유료 모드(`mock`, `toss`)에서는 3단계 버튼이 결제(기본 ₩4,900)로 바뀝니다.

## 광고(애드센스) 설정

광고 위치는 랜딩, 분석 중 화면, 순위 화면, 리포트 섹션 사이, 해설 10문항마다입니다. **문제 풀이 화면에는 광고를 넣지 않았습니다.** 보기를 누르다 광고를 잘못 누르기 쉬운 배치는 애드센스 정책 위반으로 계정이 정지될 수 있기 때문입니다.

1. 사이트를 도메인에 배포합니다. 애드센스는 실제 도메인과 콘텐츠가 있어야 심사합니다.
2. [애드센스](https://adsense.google.com)에 가입하고 사이트를 등록하면 게시자 ID(`ca-pub-...`)를 받습니다.
3. 환경변수에 `ADSENSE_CLIENT=ca-pub-...`를 설정하고 재시작합니다.
   - 광고 스크립트가 자동으로 삽입되고, 애드센스가 요구하는 `/ads.txt`도 자동으로 제공됩니다.
4. 승인되면 애드센스에서 **디스플레이 광고 단위**를 만들고 `ADSENSE_SLOT=<광고 단위 ID>`를 설정합니다.
   - 슬롯을 비워 두면 애드센스 **자동 광고**만 동작합니다.
5. 개인정보처리방침 페이지(`/#/privacy`)가 포함되어 있습니다. 애드센스 심사에서 확인하는 항목입니다.

로컬(`localhost`)에서는 광고 위치가 회색 점선 박스로 표시됩니다.

## 설계 포인트

- **채점과 결제 확인은 모두 서버가 합니다.** 정답은 클라이언트로 보내지 않습니다. IQ 점수도 결제 전 응답(`/api/results/:id`)에 들어 있지 않으므로, 개발자 도구를 열어도 점수를 볼 수 없습니다.
- **응시자마다 다른 문제를 냅니다.** 시드 기반 생성기가 문제 유형과 난이도 순서는 똑같이 유지하면서 문제 내용만 바꿉니다. 따라서 정답이 공유돼도 쓸모가 없습니다.
- **찍기 요령을 막습니다.** 오답 보기는 정답의 세 가지 속성을 2×2×2로 조합해 만들고, 그중 한 대각선 쌍을 뺍니다. 그러면 정답의 각 속성이 보기 중 정확히 절반에만 나타납니다. 그래서 "다른 보기들과 가장 많이 닮은 보기 고르기" 전략의 정답률이 무작위 수준(약 16%)에 머물고, 테스트로도 검증합니다.
- **IQ 환산 방식**
  - 난이도별 가중 정답률을 평균 100, 표준편차 15인 척도로 환산합니다.
  - 초기에는 가정한 규준(평균 50%, SD 17%)을 씁니다.
  - 응시자가 `CALIBRATION_MIN`명(기본 300명) 이상 쌓이면 **실제 응시자 분포**로 백분위를 계산합니다.
- **결제 위변조 방지**
  - 결제 금액은 서버에 저장된 주문 금액과 대조합니다.
  - 승인은 서버에서 토스페이먼츠 승인 API로 처리합니다.

## 실행

Node.js 20 이상이 필요하고, 외부 의존성은 없습니다.

```bash
npm start            # http://localhost:3000
npm test             # 문제 생성기·채점·결제 흐름 테스트
```

`.env.example`을 참고해 환경변수를 설정합니다.

```bash
node --env-file=.env server.js
```

## (선택) 실결제(토스페이먼츠) 연동

나중에 유료화할 때 쓰는 기능입니다. `PAYMENT_PROVIDER=mock`은 테스트 결제창만 띄우므로 누구나 결제 없이 리포트를 열 수 있습니다. **실제로 판매하려면 반드시 `toss`를 쓰세요.**

1. [토스페이먼츠 개발자센터](https://developers.tosspayments.com/)에서 API 키(테스트 키 또는 라이브 키)를 발급합니다.
2. 아래처럼 설정합니다.
   ```
   PAYMENT_PROVIDER=toss
   TOSS_CLIENT_KEY=test_ck_...
   TOSS_SECRET_KEY=test_sk_...
   ```
3. 결제 흐름은 다음 순서로 진행됩니다.
   1. 주문 생성 (`POST /api/results/:id/orders`)
   2. 결제창 (`requestPayment`)
   3. `/?pay=success&paymentKey&orderId&amount`로 돌아옴
   4. 서버 승인 (`POST /api/payments/confirm`)
   5. 리포트 공개

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/config` | 가격, 문항 수, 제한 시간, 결제 방식, 애드센스 설정 |
| GET | `/ads.txt` | 애드센스 판매자 선언 (`ADSENSE_CLIENT` 설정 시) |
| GET | `/api/sample` | 랜딩용 예시 문제 |
| POST | `/api/sessions` | 응시 시작. 문제 SVG를 돌려주며 정답은 포함하지 않음 |
| POST | `/api/sessions/:id/submit` | 답안 제출 → `resultId` |
| GET | `/api/results/:id` | 무료 모드는 전체 리포트, 유료 모드는 결제 전 순위 구간만 |
| POST | `/api/results/:id/orders` | 결제 주문 생성 (인증서 이름 포함) |
| POST | `/api/payments/confirm` | 결제 승인 |

## 구조

```
server.js          HTTP 서버, API, 정적 파일
lib/puzzles.js     3x3 행렬 문제 생성기 (20개 유형, 난이도 1~4) + SVG 렌더러
lib/scoring.js     가중 채점, IQ 환산, 무료 공개용 순위 구간
lib/payment.js     결제 승인 (none / mock / toss)
lib/store.js       JSON 파일 저장소 (data/db.json)
public/            프런트엔드 (바닐라 JS SPA)
test/              node:test 테스트
```
